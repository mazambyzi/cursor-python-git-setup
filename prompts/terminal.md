# Промпты для терминала

Формулировки собраны по командам, ошибкам и действиям, которые встретились в этой работе.

1. **venv и запуск скрипта**  
   В папке `cursor-python-git-setup` создай виртуальное окружение `.venv`, добавь его в `.gitignore` и запусти `hello.py` через Python из этого окружения.

2. **Ошибка `ensurepip` при создании venv**  
   `py -m venv .venv` завершился ошибкой во время `ensurepip`. Создай окружение без pip через `py -m venv --without-pip .venv` и проверь, что Python из `.venv` запускает `hello.py`.

3. **Проверка версий для сдачи**  
   Выполни в терминале `python --version` и `git --version`, сохрани точный вывод вместе с версией Cursor в `setup_versions.txt`.

4. **Чтение выданного CSV**  
   Запусти `read_csv.py` на `data.csv` с пятью строками. Покажи количество записей, имена столбцов и прочитанные строки.

5. **Опечатка при создании Git-репозитория**  
   PowerShell сообщает, что `get` не распознано, после команды `get init`. Объясни, в чём опечатка, и дай правильные команды для создания папки проекта и запуска `git init`.

6. **Настройка remote и публикация**  
   Добавь `https://github.com/mazambyzi/cursor-python-git-setup.git` как `origin`, проверь его через `git remote -v` и дай команды для коммита и отправки ветки `main`.

7. **Ошибка отправки ветки**  
   `git push -u origin main` отвечает `src refspec main does not match any`. Проверь локальную ветку и последний коммит, затем подскажи точную команду для отправки текущего `HEAD` в `main`.
